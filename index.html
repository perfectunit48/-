스마트폰에 앱으로 설치하기

현재 브라우저에서 바로 홈 화면 앱 설치가 가능합니다!

아이폰 (Safari) 홈 화면에 추가 방법

1. 하단 또는 상단의 공유 버튼(□↑)을 누릅니다.
2. 메뉴를 내려 '홈 화면에 추가'를 누르고 우측 상단 '추가'를 탭하세요.

안드로이드 (Chrome / 삼성) 앱 설치 방법

1. 브라우저 우측 상단(또는 하단) 메뉴(⋮ 또는 ≡)를 누릅니다.
2. '홈 화면에 추가' 또는 '앱 설치'를 선택하면 바탕화면에 아이콘이 생성됩니다.

저장한 파일을 모바일 브라우저나 무료 웹 호스팅에 열면 언제든 앱처럼 쓸 수 있어요.
